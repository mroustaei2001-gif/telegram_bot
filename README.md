# 🤖 ربات تلگرام "حرفِ‌تو"

ربات تلگرامی حرفه‌ای برای مدیریت موضوع روز، دریافت پیام ناشناس/با هویت، و توزیع پروکسی و کانفیگ با سیستم دعوت دوستان و پنل مدیریت کامل.

## ✨ قابلیت‌های کاربران

- ✅ عضویت اجباری در کانال اصلی و کانال‌های تبلیغاتی
- 📌 موضوع روز با قابلیت بروزرسانی
- 📩 پیام ناشناس (بدون یوزرنیم)
- 👤 پیام با هویت (با یوزرنیم)
- 💡 پیشنهاد ایده برای موضوع روز
- 🎁 پروکسی هدیه (سیاست ۲۴ ساعته + دعوت ۲ نفر)
- 📦 کانفیگ 500 مگ (سیاست ۲۴ ساعته + دعوت ۴ نفر)
- 🔗 سیستم دعوت دوستان با لینک اختصاصی
- 📜 قوانین و معرفی

## 🛠️ قابلیت‌های پنل ادمین

- 👥 لیست کاربران با مشخصات کامل
- 💡 لیست ایده‌های ارسالی کاربران
- 📢 مدیریت کانال‌های تبلیغاتی (افزودن/حذف/فعال‌سازی)
- 🔒 مدیریت عضویت اجباری (فعال/غیرفعال)
- 🎁 مدیریت پروکسی (فعال/غیرفعال + افزودن پروکسی)
- 📦 مدیریت کانفیگ (فعال/غیرفعال + افزودن کانفیگ)
- 📡 تغییر کانال اصلی
- 📊 آمار کلی ربات

## 🚀 نصب و راه‌اندازی

1. **کلون کردن مخزن:**
   ```bash
   git clone https://github.com/YOUR_USERNAME/telegram-bot.git
   cd telegram-bot
   ```

2. **ساخت محیط مجازی:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # لینوکس/مک
   venv\Scripts\activate     # ویندوز
   ```

3. **نصب کتابخانه‌ها:**
   ```bash
   pip install -r requirements.txt
   ```

4. **تنظیم فایل `.env`:**
   ```env
   TELEGRAM_BOT_TOKEN=YOUR_TOKEN
   ADMIN_ID=YOUR_USER_ID
   ```

5. **اجرای ربات:**
   ```bash
   python bot.py
   ```

## 📝 دستورات ادمین

- `/admin` - باز کردن پنل مدیریت
- `/settopic <متن>` - تنظیم موضوع روز
- `/stats` - مشاهده آمار ربات

## 🎯 راهنمای استفاده از پنل ادمین

1. دستور `/admin` را در ربات ارسال کنید
2. از منوی نمایش داده شده، گزینه مورد نظر را انتخاب کنید
3. برای تغییر کانال اصلی، از گزینه "📡 تغییر کانال اصلی" استفاده کنید
4. برای افزودن پروکسی/کانفیگ، از گزینه‌های مربوطه استفاده کنید
5. برای مدیریت کانال‌های تبلیغاتی، از گزینه "📢 مدیریت تبلیغات" استفاده کنید
